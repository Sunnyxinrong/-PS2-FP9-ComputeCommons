Who gets the inference slot?

Compare a standard auction with access credits and worker-selected reservations. Predict the payment before seeing the outcome.

Evidence boundary: this is a synthetic educational model. It has no human bidding dataset and runs no robot. Reserved capacity is an opportunity, not a measured safety or welfare gain.

1. Understand the decision

Three embodied-AI operators, A, B and entrant E, compete for two identical high-quality inference windows. Each can use at most one. Each knows its own value. E has verified entrant status. Worker-selected supervised evaluations receive any reserved windows before the commercial auction.

Allocation, payment and stopping rules

All bids close at one deadline. Rank score = bid + credit for verified E. Award the remaining windows to the top scores, using A before B before E for ties. A winner pays the highest losing score minus its own eligibility credit, floored at zero. Losers pay zero. If all firms win, the cutoff is zero. If all windows are reserved, no firm wins. The round then ends.

This is a simultaneous game with incomplete information. Truthful value reporting is weakly dominant and hence a Bayesian Nash equilibrium under private values, unit demand and committed rules. It is not the only report that can give the same payoff. Eligibility must be verified separately.

Manual entry cannot enforce secrecy. A facilitator should collect sealed bids off-screen. The example values are educational inputs, not observations.

Enter independently collected bids only after all peers have committed. The selected operator's bid below replaces its field here.

3. Inspect the outcome

A nontruthful bid with zero regret need not be a harmful mistake. A correct payment prediction alongside rejection of the rule motivates a legitimacy question; it does not by itself prove a cause.

4. Challenge the institution

Under reserve 1 and credit 5, truthful values (10, 9, 6) select E at payment 5. If A falsely gets entrant status, A instead wins and pays 6, earning 4. Honest value bidding cannot prevent a false eligibility claim. An idealized audit with probability a and additional fine L deters this one deviation only when a × L ≥ 4.

For a real OpenVLA-based testbed, first measure whether the windows meet common latency and compatibility requirements. Audit entrant eligibility before bidding, record worker-selected task use, and provide an appeal channel. No safety certification follows from a high bid.
